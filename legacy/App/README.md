# Система навигации ArUco

Система для определения координат объекта с меткой ArUco и управления движением машинки через веб-интерфейс.

## Структура проекта

```
LocalNavigaion/
├── src/
│   ├── aruco/              # Модуль работы с ArUco метками
│   │   ├── __init__.py
│   │   ├── detector.py      # Детекция меток и работа с камерой
│   │   └── coordinates.py  # Система координат
│   ├── navigation/         # Модуль навигации
│   │   ├── __init__.py
│   │   └── controller.py   # Контроллер навигации и движения
│   └── web/               # Веб-интерфейс
│       ├── app.py         # Flask сервер
│       └── templates/
│           └── index.html # HTML интерфейс
├── main.py                # Главный файл запуска
├── requirements.txt       # Зависимости
└── README.md              # Документация
```

## Установка

1. Создайте виртуальное окружение (если еще не создано):
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Убедитесь, что вы в группе `video` для доступа к камере:
```bash
sudo usermod -a -G video $USER
# Перелогиньтесь после этого
```

## Запуск

### Базовый запуск (IP машинки по умолчанию: 192.168.1.100)
```bash
python main.py
```

### Запуск с указанием IP адреса машинки
```bash
python main.py --robot-ip 192.168.1.50 --robot-port 5000
```

Параметры:
- `--robot-ip` - IP адрес машинки на Raspberry Pi (по умолчанию: 192.168.1.100)
- `--robot-port` - Порт Flask сервера на машинке (по умолчанию: 5000)

После запуска откройте браузер и перейдите на `http://localhost:5000`

## Настройка машинки на Raspberry Pi

На машинке должен быть запущен Flask сервер с эндпоинтом `/move`, который принимает POST запросы с JSON:
```json
{"direction": "forward"}
```

Доступные команды:
- `forward` - движение вперед
- `backward` - движение назад
- `left` - поворот налево
- `right` - поворот направо
- `stop` - остановка

## Использование

1. **Определение координат**: Система автоматически определяет координаты метки с ID 0 относительно стационарных меток (ID 1-4)

2. **Установка цели**: В веб-интерфейсе введите координаты X и Y (от 0.0 до 1.0) или кликните на карте координат

3. **Движение**: Машинка автоматически начнет движение к целевой точке

4. **Остановка**: Нажмите кнопку "Остановить" для прекращения движения

## Настройка

- **Стационарные метки**: ID 1, 2, 3, 4 (можно изменить в `main.py`)
- **Подвижная метка**: ID 0 (можно изменить в `main.py`)
- **Точность движения**: `tolerance` в `NavigationController` (по умолчанию 0.02)
- **IP машинки**: можно указать через параметр `--robot-ip` при запуске

## Архитектура

Система состоит из нескольких модулей:

1. **ArUco модуль** - детекция меток и вычисление координат
2. **Навигационный модуль** - вычисление команд движения на основе текущей и целевой позиции
3. **Исполнитель команд** - отправка HTTP запросов на машинку
4. **Веб-интерфейс** - GUI для управления и мониторинга
