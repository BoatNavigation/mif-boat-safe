# Бэклог улучшений (без изменений runtime)

Ниже перечислены пункты, выявленные при структурной очистке. Их можно реализовать позже, не меняя текущий объем рефакторинга.

## Высокий приоритет

- Добавить тесты для mission-flow:
  - control center REST -> MQTT publish
  - переходы состояний миссии на vehicle
  - публикация позиций в navigation server
- Заменить заглушки в:
  - `system/vehicle/services/obstacle_detection.py`
  - `system/vehicle/services/obstacle_avoidance.py`
- Добавить CI-пайплайн (lint + tests) для защиты рабочего стека `system`.

## Средний приоритет

- Унифицировать и задокументировать управление зависимостями:
  - решить, нужен ли корневой `requirements.txt`
  - держать источник истины по зависимостям в одном месте (`system/requirements.txt` или корень)
- Добавить healthcheck/readiness endpoints для всех сервисов.
- Добавить структурированный формат логов и correlation ID для MQTT-потока сообщений.

## Низкий приоритет

- Пересмотреть использование `sys.path.insert(...)` в точках входа и заменить на более безопасную пакетную схему запуска.
- Добавить migration notes, если какие-либо скрипты/инструменты все еще зависят от старых путей в корне.
